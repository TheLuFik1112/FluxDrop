# FluxDrop

Локальная передача файлов, папок и текста между телефонами — без интернета, без облака и
без аккаунтов. Устройства находят друг друга в одной Wi-Fi сети (и по Bluetooth), соединяются
напрямую и передают данные по TLS.

## Что умеет

- **Пакет отправки**: сначала собираете файлы, папку или текст, потом выбираете получателя.
- **Входящая шторка поверх любых приложений**: запрос на приём показывается снизу экрана,
  даже если FluxDrop свёрнут.
- **«Всегда принимать от …»**: ключ устройства запоминается, следующие передачи приходят без
  вопросов — только тихий прогресс в уведомлении.
- **Докачка**: файл режется на куски по 4 МБ, каждый проверяется по SHA-256; оборванная
  передача продолжается с места обрыва.
- **Веб-портал**: включается в настройках, показывает QR — любой браузер в той же сети может
  скачать файлы с телефона или закинуть свои.
- **Плитка в быстрых настройках**: один тап — текст из буфера уходит последнему доверенному
  устройству, которое сейчас видно в сети.

## Установка

1. Скачайте APK (файл `app-debug.apk`) — он лежит в артефактах сборки.
2. Откройте файл на телефоне. Android спросит разрешение на установку из этого источника —
   разрешите.
3. Запустите FluxDrop и выдайте разрешения:
   - **Уведомления** — для запросов на приём;
   - **Устройства поблизости** (Android 12+) — для Bluetooth;
   - **Файлы и медиа** — при первом выборе файлов.

## Как включить шторку поверх других приложений

Настройки → «Фоновая работа» → **«Шторка поверх других приложений»** → «Разрешить» и включите
переключатель в системных настройках. Без этого разрешения запрос придёт уведомлением с
кнопками «Принять / Отклонить» — это тоже работает.

Там же стоит нажать **«Не оптимизировать батарею»**: иначе Android может усыпить приём в фоне.

## Как отправить

1. На вкладке «Отправить» нажмите **Файлы**, **Папка** или **Текст** — соберите пакет.
2. Второе устройство должно быть в той же Wi-Fi сети и с запущенным FluxDrop.
3. В списке «Устройства рядом» нажмите **Отправить**.
4. На втором телефоне появится шторка: **Принять** или **Отклонить**.

Принятые файлы складываются в папку **Download/FluxDrop** (внутри неё сохраняется структура
папок отправителя). Текст попадает в буфер обмена.

## Где это собрать

На телефоне собрать нельзя — нужен компьютер или облако.

### Вариант 1. GitHub Actions (проще, ничего устанавливать не надо)

1. Создайте пустой репозиторий на github.com.
2. Загрузите туда **содержимое папки `FluxDrop`** (файл `.github/workflows/build.yml` уже внутри).
3. Откройте вкладку **Actions** → сборка «Build APK» запустится сама. Через несколько минут
   в разделе **Artifacts** будет `FluxDrop-debug` — это zip с APK.

### Вариант 2. Android Studio

1. Установите [Android Studio](https://developer.android.com/studio).
2. **File → Open** → выберите папку `FluxDrop`.
3. Дождитесь синхронизации Gradle и нажмите **Run ▶** (телефон подключён по USB) или
   **Build → Build App Bundle(s) / APK(s) → Build APK(s)**.

Проект собирается на JDK 17, Gradle 8.10.2, Android Gradle Plugin 8.7.3, compileSdk 35,
minSdk 26 (Android 8.0).

## Структура проекта

```
FluxDrop/
├─ app/src/main/java/app/fluxdrop/
│  ├─ core/        модели, идентичность и TLS, пакет отправки
│  ├─ data/        настройки, доверенные устройства, история (JSON + SharedPreferences)
│  ├─ discovery/   UDP-мультикаст, mDNS (NSD), BLE-присутствие
│  ├─ net/         TLS-сервер, клиент отправки, приём чанков, веб-портал
│  ├─ overlay/     шторка поверх приложений и прозрачная Activity
│  ├─ service/     foreground-сервис, уведомления, приёмники кнопок
│  ├─ tile/        плитка быстрых настроек
│  └─ ui/          Compose Material 3: главный экран, история, настройки
├─ docs/           архитектура и разбор манифеста
└─ .github/        workflow для сборки APK
```

## Технические детали (коротко)

- Порт TLS-сервера — `53530`, веб-портал — `53531`, обнаружение — `53532`.
- Каждое устройство имеет ключ EC P-256. Идентификатор = SHA-256 открытого ключа.
- Запрос на передачу подписывается ключом отправителя; получатель проверяет подпись и
  соответствие ключа сертификату.
- Доверие — по отпечатку ключа (первое подтверждение запоминается). Отозвать можно в
  настройках.

Подробнее: `docs/ARCHITECTURE.md` и `docs/ANDROID_MANIFEST.md`.
